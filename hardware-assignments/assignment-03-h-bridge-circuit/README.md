
# H-Bridges and Schematics

For this assignment, we were to design an (simple?) H-bridge circuit capable of controlling the direction of rotation of a DC motor using Proteus.


## How does the circuit work?
An H-bridge circuit is a simple DC motor driver configuration which allows us to control both the rotational speed and direction of such electric motors by using a fixed DC voltage or by pulse width modulation (PWM).

Components:
1. 4 Switches labeled S1, S2, S3 and S4 respectively.
2. 12V DC motor
3. Voltage Source, 12V
